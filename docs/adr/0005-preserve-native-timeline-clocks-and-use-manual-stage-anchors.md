# Preserve native timeline clocks and use manual stage anchors

SC2 Copilot 按灰机 Wiki 表格表达的原生时间语义保存和运行地图事件，不把阶段相对时间、剩余倒计时、条件触发或重复间隔近似成开局绝对时间。具有明确开局时间的事件自动运行；锚点明确但本机 6119 状态无法提供的夜晚、主目标等阶段由玩家手动标记开始；依赖持续 OCR、视觉条件或未确认锚点的事件只保留数据并标记为暂不支持。手动锚点只属于当前对局，允许重新标记和清除，并在离开对局、开始新局或游戏时间重置时自动丢弃。这样会增加少量手动操作并使部分已抓取数据暂时不产生提醒，但避免错误计时，也允许未来的视觉状态提供器替换手动锚点而不改变调度模型。
