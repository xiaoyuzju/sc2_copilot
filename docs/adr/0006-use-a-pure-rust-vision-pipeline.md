# Use a pure Rust vision pipeline

SC2 Copilot 的视觉能力采用 Windows 原生画面采集与纯 Rust 图像处理，不把
OpenCV、Python、神经网络运行时或外部模型 DLL 加入发布版。

采集和识别位于两个独立 seam：

- Windows adapter 发现 SC2 客户区、采集最新画面并裁剪规范化 ROI。
- `sc2-copilot-vision` 把 ROI 像素转换为稳定语义证据。

视觉 module 使用 `image` 作为像素容器，使用 `imageproc` 提供基础形态学和连通域
标记；颜色变换、几何评分、候选跟踪和状态机留在项目实现中。模板和标定数据必须由
本项目独立采集，记录来源并嵌入可执行文件。

视觉结果必须携带会话身份。应用控制器拒绝旧会话结果，并按“用户手动选择 > 稳定
视觉结果 > 目录默认值”处理地图分支。视觉不可用或无证据不会覆盖已有选择。

这个决策保持 Cargo-only、离线和精确 ZIP 发布，同时允许用录制 ROI 替换实时采集做
确定性测试。OpenCV 可以作为不进入发布包的开发期对照工具；只有纯 Rust 方案经过
ROI 裁剪、缓冲复用和预计算后仍无法达到精度或性能目标时，才重新评估运行时依赖。
