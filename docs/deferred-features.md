# Deferred Features

本文件记录已经识别、但不进入首个可交付版本的能力。它们不是当前实现的扩展点或兼容性承诺；启动其中一项前，需要重新确认需求、数据来源和性能目标。

游戏窗口采集、坐标模型以及“往日神庙”/“虚空撕裂”的小地图红点自动分支已经实现，不再列为延期能力；当前支持边界见 [视觉方案](vision-design.md)。

## Alert delivery

### Notification sound provider

为已经定义的提醒播放端口选择并实现具体提供器，包括提示音内容、音频格式、播放库、音量策略、默认开关，以及是否支持 Windows 系统文字转语音。

当前只保留播放接口，不采用 Keiframe 的任何音频文件、文件名、文字转语音策略或播放实现。

完成条件：提示音拥有独立来源；播放不会阻塞调度器；设备不可用、播放失败、快速连续批次和应用退出都有确定行为。

## Shared foundation

### Conditional and composite timeline triggers

为灰机 Wiki 中当前标为 `condition_unavailable`、`source_expression_unsupported` 或 `ambiguous_clock` 的行，独立建模 `WhenCondition`、`After`、`AnyOf` / `AllOf` 和 `Repeat`。首版不会为了提高自动覆盖率，把条件、依赖或重复间隔近似成开局绝对时间。

完成条件：每种表达式都有明确的状态输入与时钟语义；依赖关系无环；重复次数或终止条件有界；暂停、重连、时间回退和晚启动的行为均有确定性测试；原先的 `unsupported` 行可逐条迁移且保留原 `SourceRef`。

## Recognizers

### Enemy race and mutator recognition

从指定界面区域识别敌方种族与当前突变因子，以替代首版的手动突变选择，并只在获得稳定证据后发布结果。

完成条件：模板或其他识别资源拥有独立来源；连续帧确认、超时、未知结果和误识别恢复都有测试。

### Supply recognition and alert

识别右上角当前人口与人口上限，在满足可配置余量规则时显示补给提醒。

完成条件：支持目标游戏语言和常用分辨率；解析必须校验数字位数、分隔符和 `current <= max`；识别失败不会沿用陈旧结果。

### Malwarfare status recognition

识别“净网行动”的 UI 偏移、已净化节点数、阶段倒计时和暂停状态，并据此驱动该地图的动态时间线。

首版已经保存该地图的原始时间与触发表，但不会把阶段剩余倒计时近似为开局绝对时间，也不启用相关动态提醒。本能力完成后为已有事件提供运行时状态，不要求重新定义地图时间表。

完成条件：节点颜色、语言、英雄或回放导致的 UI 偏移均有夹具；时间跳变、短暂闪烁、阶段切换和暂停恢复可确定性回放。

### Artifact readiness recognition

识别英雄存活状态和神器指示器，在图像模式、定时模式及手动保底恢复之间维护明确状态机并生成就绪提醒。

完成条件：初始验证、英雄门控、就绪、回到空闲、冷却、定时锚点、超时和保底恢复均有状态迁移测试；视觉证据不可用时不误报。

## Recommended delivery order

1. 敌方种族与突变识别。
2. 补给识别。
3. 净网行动状态识别。
4. 神器就绪识别。
