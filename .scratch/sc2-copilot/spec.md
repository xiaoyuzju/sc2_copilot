# Initial Release Scope

首个可交付版本只使用 SC2 在本机 6119 端口提供的只读 HTTP 状态和用户在 SC2 Copilot 中的显式操作。它不采集或分析游戏窗口画面。

## Included

首版地图验收范围是灰机 Wiki 总览中的全部 15 张基础地图，不以少数样例地图作为完成标准。每张地图的相关表格都必须编译为可运行事件，或以可追溯原因标记为 `unsupported`；不允许静默忽略。

- 检测游戏进程可用性以及进入、离开对局的会话生命周期。
- 读取并规范化游戏时间、玩家列表和界面状态。
- 根据玩家列表自动识别合作任务地图。
- 从灰机 Wiki 合作任务页面独立整理地图时间表，并保存来源页面和采集日期。
- 使用 Keiframe 固定基线进行时间表差异与遗漏检查，不迁移其数据结构或提示文案。
- 将审核后的规范化 JSON 在构建时嵌入 Rust 可执行文件；应用运行时不加载外部时间表，也不访问灰机 Wiki。
- 自动驱动具有明确开局绝对时间的地图事件和用户倒计时。
- 允许玩家手动标记、重新标记或清除夜晚、主目标等明确阶段的开始，为阶段相对事件建立只在当前对局有效的计时锚点。
- 提供默认 30 秒、全局可配置的事件提醒提前量；每个事件在当前对局只发出一次播放请求和弹窗，到点不重复请求播放。
- 将最终触发时刻相同的事件合并为一次播放请求和一个弹窗，同时在覆盖层中分别展示。
- 启动较晚、恢复连接或游戏时间向前跳跃时不补发已经到点的事件；仍在未来且已进入提前窗口的事件立即提醒一次。
- 提供地图分支和突变因子的手动选择，让相关时间线在没有视觉识别时仍可使用。
- 覆盖层默认鼠标穿透；通过可配置全局热键临时打开当前地图的交互面板，用于阶段锚点操作。
- 事件弹窗使用覆盖层内部的临时提示卡片，不调用 Windows 通知中心，也不抢占游戏焦点。
- 提供提醒所需的覆盖层、可替换播放接口、托盘、设置和诊断入口；具体提示音方案暂不决定。
- 提供离线遥测回放与确定性测试工具。

## Deferred

- 视觉相关能力统一记录在 [Deferred Features](../../docs/deferred-features.md) 中。
- “净网行动”依赖已净化节点数和持续倒计时状态，首版只保留数据，不启用动态提醒。
- 不单独提供敌方种族手动选择；只有出现实际消费该信息的首版能力时才重新评估。

延期功能不属于当前版本的隐藏扩展点；需要重新进入设计流程后再加入。

## Data Verification Boundary

首版只执行“灰机 Wiki 基线录入”和“Keiframe 差异检查”两步，不追踪官方补丁说明，也不安排游戏实测或回放验证。因此数据状态只表示其与两个选定来源的关系，不表示已由官方或当前游戏版本确认。

重复抓取与更新步骤记录在 [Update Map Schedule Data](../../docs/runbooks/update-map-schedule-data.md) 中。
